# projects

Personal projects repository.

## Setup

Make sure git is installed before starting a local session:

```bash
# macOS
brew install git

# Ubuntu/Debian
sudo apt install git

# Windows
winget install Git.Git
```

## Local Claude Code Sessions

Install the Claude Code CLI:

```bash
npm install -g @anthropic-ai/claude-code
```

Then start a session from this directory:

```bash
claude
```
